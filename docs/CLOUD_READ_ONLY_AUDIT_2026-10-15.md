A controlled L4 evaluation would have a 24 GB VRAM device with at least 4 CPU and 16 GiB RAM on Cloud Run, but this project has no verified Cloud Run GPU allocation and Mumbai Cloud Run L4 requires invitation. Compute Engine's project-wide GPU cap is zero. Vertex's L4 serving quota of one does not clear billing or actual capacity. No GPU route is approved or provisioned.
