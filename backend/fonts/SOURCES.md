# Bundled caption fonts

NotoSans-Regular.ttf was downloaded on 12 October 2026 from the official Noto archive:
https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Its SIL Open Font License is in NotoSans-LICENSE.txt. The other previously bundled
Noto script fonts use LICENSE.txt. The Latin font is copied alongside the selected
script font for every render so brand names and English text do not depend on the
host operating system's installed fonts.
