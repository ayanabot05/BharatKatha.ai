## Indic Parler access and compute checkpoint

- **BLOCKED — access:** The [upstream model page](https://huggingface.co/ai4bharat/indic-parler-tts) requires a logged-in user to accept terms before weight access. The local `huggingface_hub.get_token()` check returned false; no token was printed or used. We therefore cannot verify that a specific account has been approved for gated weights.
- **BLOCKED — local runtime:** The checkpoint is about 0.9B float32 parameters and its listed weight file is about 3.75 GB. This machine had 23.79 GiB total RAM, 6.08 GiB available RAM and 3.80 GB free on `C:` at this checkpoint. `torch` and `parler_tts` are not installed in the current Python environment. `nvidia-smi` is unavailable; that alone does not prove a GPU is absent. Model load plus runtime and output space were not measured. No large weights were downloaded.
- **BLOCKED — Cloud availability:** The configured project is `ayana-video-studio`. `gcloud auth list` could not access the local SDK credential database inside the sandbox; an earlier read-only billing query outside it reported that the SDK token needs interactive reauthentication. Current billing state, L4 quota, capacity and GPU eligibility remain unknown. No GPU deployment or charge occurred.
- **BLOCKED — commercial sign-off:** The [model card](https://huggingface.co/ai4bharat/indic-parler-tts) says Apache 2.0 for the checkpoint. It also lists several training datasets, with one license abbreviated `CC V1`; attribution/output obligations require a final rights review before production hosting. A model license tag alone is insufficient production clearance.
- **BLOCKED — controlled test cost:** [Cloud Run documentation](https://cloud.google.com/run/docs/configuring/services/gpu) lists an L4 with 24 GiB VRAM and at least 4 vCPU/16 GiB memory. [Published pricing](https://cloud.google.com/run/pricing) gives a non-zonal L4 rate of USD 0.0001867 per second plus CPU and memory. At the page's base instance rates, a 15-minute 4-vCPU/16-GiB/L4 runtime is approximately USD 0.262 before regional variation, build, storage, networking, taxes and cold setup. This is a planning example, not a project quote or spending authorization. Exact pricing, billing and quota must be checked after reauthentication.
